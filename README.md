Haunted Mansion
A 3D horror exploration game built with **JavaScript and Three.js
About the Game
Haunted Mansion is a first-person 3D exploration game set inside a mysterious, abandoned mansion. The goal is to create an atmospheric environment using warm candlelight, dark surroundings, and interactive elements.
